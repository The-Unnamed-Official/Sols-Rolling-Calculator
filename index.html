01
Recommended path

Start your first simulation

  1. Enter your Luck Total and Roll Amount, or load both from Quick Presets.
  2. Choose the biome, rune, time, and any events that should be active.
  3. Select Unnamed's or Sol's-Like processing in the Simulation Console, then press Roll.
  4. Review, search, sort, or share the completed results in the Sequence Monitor.
02
Core inputs

Luck, rolls, and multipliers

Luck Total is the base luck used for the run. Roll Amount is how many RNG attempts are processed in Single Potion Mode.

  • VIP, Dorcelessness, We're Sorry, YG Blessing, and Astrald's Blessing are optional final multipliers in the Simulation Console.
  • The reset buttons return the related field to its default value.
  • True Chance Display can add a calculated “1 in X” line to eligible results without changing the roll.
03
Faster setup

Quick Presets

The preset banks provide ready-made values for Luck, Devices, and Roll Counts.

  • Click a preset card to apply it immediately.
  • Hover or keyboard-focus supported luck presets to reveal the −/+ controls for removing or adding that exact value.
  • Device presets represent combined gear and buffs; roll presets only replace the roll amount.
04
Item rules

Potions and Multiple Potion Mode

Single Potion Mode uses one luck value and roll amount. Multiple Potion Mode processes the quantity entered for each potion as ordered batches.

  • With compatible stacking off, each potion keeps its own batch. With stacking on, compatible potion luck is merged per roll.
  • The existing priority is preserved: Oblivion, Pump King's Blood, Tutorial Potion, then the remaining potion types.
  • Oblivion, Pump King's Blood, and Tutorial Potion always remain separate. Rune-incompatible potion rolls are processed without the rune before compatible rolls.
  • Red Moon I and Red Moon II are mutually exclusive within a stack. Each can still stack with other compatible potions.
  • Device preset luck is applied before VIP, final-luck, and biome multipliers.
05
Environment

Biomes, runes, and time

The Environment module combines a primary biome or dimension, an optional rune, and Day or Night.

  • Biome shortcuts quickly load Glitch, Singularity, Cyberspace, Dreamspace, or Limbo combinations.
  • Use RoE enables Rune of Everything without resetting your selected biome or time.
  • Reset Biome returns the environment selection to its normal state.
  • Developer Biomes unlocks the simulator's developer-only environments.
06
Availability rules

How biome and event rules work

  • Native-biome and breakthrough rules use the selected biome, rune, and time to choose the correct aura chance.
  • Event auras are available only when their matching event is enabled. The Events menu supports multiple compatible event selections.
  • Some blessings, Admin Abuse choices, and developer biomes have extra availability rules; the simulator warns you when a required condition conflicts.
  • Glitch and Rune of Everything follow their own supported availability lists rather than blindly enabling every aura.

Changing the display method never changes these rules or their probability calculations.

07
Processing & display

Simulation methods and live controls

  • Unnamed's is the default: it processes the run, completes the progress bar, then shows the result totals.
  • Sol's-Like uses the same RNG and rules but displays every visible aura in exact roll order while progress advances.
  • The attached pause button safely stops after the current roll. Resume continues from the next unprocessed roll, and speed can be changed while paused.
  • Cancel safely ends the active run. Simulation methods cannot be changed during an active run.
08
Result visibility

Filter Aura Tiers and individual auras

Open Settings → Rolling Settings to access both filter menus.

  • Filter Aura Tiers hides whole rarity bands such as Legendary or Mythic.
  • Filter Auras hides only the exact auras you toggle. Reset Selection turns every individual aura filter off.
  • Filters apply to Unnamed's results, Sol's-Like live entries, sharing, and filtered cutscene presentation.
  • Filtering is display-only: RNG calls, potion processing, progress, totals, and statistics are unchanged.
09
Cinematic playback

Cutscenes

  • Enable Cutscenes from Settings; fullscreen is recommended for the intended presentation.
  • During Sol's-Like rolling, a cutscene pauses rolling and progress at that exact aura, then resumes at the next roll in sequence.
  • Automatically pause rolling after cutscene leaves the run paused until you press Resume yourself.
  • Cutscene controls can skip the current cinematic or all remaining cinematics without restarting the roll sequence.
10
After rolling

Sequence Monitor, sorting, and sharing

  • Search accepts either an aura name or a tier name such as Legendary.
  • Unnamed's results can sort by Rarity or Alphabetical. Sol's-Like also offers Recent to restore exact roll order.
  • Share Result exports the currently available summary through the supported text and image options.
  • While live rolling, scrolling upward disables automatic following. Use the down-arrow button to follow the newest rolls again.
  • The summary includes run parameters, XP milestones, totals, and statistics after completion.
11
Preferences

Audio, quality, and advanced settings

  • Mute controls all sound. Audio Settings separately adjust music, cutscenes, obtain sounds, and UI sounds.
  • Quality Preferences can remove particles, UI animations, shake effects, roll/sigil animation, or reduce/remove glitch effects.
  • Allow Background Rolling keeps active simulations processing when the tab is not focused, which may use more CPU or battery.
  • True Chance Display adds eligible real-chance context to the feed without modifying results.
